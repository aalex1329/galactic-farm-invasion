# Galactic Farm Invasion v0.1

Original Godot 4 mobile arcade shooter prototype.

## Included
- Portrait 720x1280 gameplay
- Touch/drag ship movement
- Automatic shooting
- Enemy formations
- Escalating waves and enemy health
- Enemy projectiles
- Score and 3 lives
- Explosion particles
- Game-over and tap-to-retry
- Original procedural placeholder graphics

## Run
1. Install Godot 4.x.
2. Import `project.godot`.
3. Press F6/F5 or the Run button.

The next development stage can add polished original artwork, bosses, power-ups,
weapon upgrades, menus, sound/music, progression, save system, Android export,
and later optional Solana Mobile integration.
